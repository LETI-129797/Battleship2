## 4. Reflexão
A ferramenta detetou com sucesso o cheiro Long Parameter List sem identificar falsos positivos, sinalizando corretamente o método que ultrapassou o limite de 5 parâmetros. No entanto, o seu foco puramente quantitativo pode gerar falsos negativos a nível de design, aprovando métodos que, apesar de terem menos parâmetros, deveriam logicamente ser agrupados num único objeto. Relativamente às estratégias de Martin Fowler, a inspeção apresenta limitações por não compreender o contexto dos dados, limitando-se a sinalizar a anomalia numérica sem avaliar a coesão concetual necessária para sugerir uma refatorização adequada.
